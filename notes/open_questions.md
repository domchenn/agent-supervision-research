# Open questions (for Prof. McLaughlin)

## Scope
- I'd like to start with sycophancy alone and bring in reward hacking later. Does that fit what you had in mind?
- What does "agent-based modeling" mean for this project: an analytical game-theory model, a simulation (e.g. Mesa), or experiments with real LLM agents?

## Supervision design
- Should the supervisor work as a correction loop (check every answer) or a deterrent (occasional audits with penalties)? When does each work?
- What happens when the supervisor is itself an LLM that can be flattered?
- How can a supervisor tell sycophancy apart from legitimate agreement with a user who happens to be right?

## Reward hacking (later)
- When, if ever, is reward hacking beneficial? How would a supervisor tell a creative solution from a hack?
- If we clamp down on sycophancy, should we expect agents to substitute into reward hacking?
- Is "reward hacking through persuasion" (Wen et al. 2024) a third failure mode, or does it blur the line between the two?
